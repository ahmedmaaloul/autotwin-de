# Data licences

The Apache 2.0 licence in [`LICENSE`](LICENSE) covers **the source code of AutoTwin DE only**.
It does not, and cannot, relicense the datasets this project ingests. Each source keeps its own
terms, and those terms follow the data wherever it goes — including into `data/`, into the
PostGIS database, and into anything you publish from them.

Nothing here is legal advice. Verify the terms at the source before any use beyond development.

> **Caveat — read this.** The Autobahn API is served publicly and without authentication, and
> its OpenAPI specification is maintained in the federal `bundesAPI` organisation, but no

> locally, never redistributed as a dataset, and the request rate is deliberately low. If you
> intend to build on this source commercially or redistribute it, contact Autobahn GmbH or use
> the [Mobilithek](https://mobilithek.info/) DATEX II feeds, which carry explicit terms.

### Map tiles

Vector basemap tiles are served by a keyless community provider (configured in
`apps/web/lib/map/style.ts`). Tile data is derived from **OpenStreetMap (ODbL 1.0)**; the
attribution string is always rendered on the map and must not be removed. The provider is a
single configurable constant — see the README for the swap procedure and each provider's terms.

## Simulated data

Vehicle telemetry, trips, battery measurements and any ML training labels derived from them are
**generated by AutoTwin DE** and carry `data_origin = simulated`. They are released under the
same Apache 2.0 licence as the code. They describe a physics model, not real vehicles, and must
never be presented as measurements of a real fleet.

## What this project does with the data

- Raw downloads are kept under `data/raw/` with the source URL and a SHA-256 of the payload,
  so any derived table can be traced back to the exact bytes it came from.
- Every database row carries `source`, `source_url`, `source_timestamp`, `ingestion_run_id`
  and `data_origin`.
- `data/` is git-ignored. This repository redistributes **no** third-party dataset. The only
  committed samples are small fixtures used to test the parsers, each documented with its
  origin in `services/ingestion/src/autotwin_ingestion/fixtures/README.md`.
